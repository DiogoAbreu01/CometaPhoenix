# Cometa Phoenix v0.13 ? galeria ampliada (20/11/2026)

**20 novas capturas individuais**, feitas com o executavel real em Windows / Radeon RX 580 / OpenGL 3.3.
As imagens mostram interfaces, quatro circuitos, corridas, oficina e campeonato.
A conquista P1 do campeonato foi de um teste automatizado com piloto automatico, nao de um jogador humano.
As montagens usam apenas as capturas reais, redimensionadas e legendadas.
